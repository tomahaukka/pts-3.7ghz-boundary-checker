# PTS Sweden 3.7 GHz Private 5G Boundary Compliance Checker

A lightweight open-source Python engine developed by Radiometric Analytics for validating PTS Sweden technical coexistence rules and worst-case boundary RSRP levels for private 5G non-public networks in the 3.7-3.8 GHz spectrum band.

## Features
- FSPL and RSRP Calculation: Free Space Path Loss modeling accounting for building envelope attenuations.
- PTS Boundary Coexistence Analysis: Calculates worst-case received power across site boundary coordinates in SWEREF 99 TM.
- Zero Heavy Dependencies: Lightweight Python module easily integrable into spatial planning software, automated APIs, or QGIS pipelines.
